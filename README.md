# Homebrew Veyqa

Install Veyqa Voice on an Apple Silicon Mac running macOS 13 or later:

```bash
brew install --cask wjc-dev/veyqa/veyqa-voice
```

Upgrade:

Quit Veyqa Voice before updating, then reopen it from Applications. Your credentials and settings are retained.

```bash
brew update
brew upgrade --cask wjc-dev/veyqa/veyqa-voice
```

Uninstall:

```bash
brew uninstall --cask veyqa-voice
```
